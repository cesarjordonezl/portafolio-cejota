## ⚙️ Instalación y ejecución local

Para ejecutar este proyecto en tu equipo, necesitas tener instalado Node.js y npm.

1. Clona el repositorio:

   ```bash
   git clone https://github.com/cesarjordonezl/portafolio-cejota.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd portafolio-cejota
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

5. Para generar la compilación de producción:

   ```bash
   npm run build
   ```
